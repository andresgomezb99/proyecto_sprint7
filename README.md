# Proyecto de Ingeniería de Datos - Análisis de Vehículos en EE. UU. (Sprint 7)

Esta es una aplicación web interactiva desarrollada con **Streamlit**, **Pandas** y **Plotly** que permite explorar y analizar un conjunto de datos sobre anuncios de venta de coches en Estados Unidos.

## 🚀 Funcionalidad de la Aplicación

La aplicación proporciona un cuadro de mandos dinámico donde el usuario puede:
* **Visualizar la distribución del kilometraje (Odómetro):** Mediante un histograma interactivo activado por casilla de verificación.
* **Analizar la relación entre Precio y Kilometraje:** Generando un gráfico de dispersión (*scatter plot*) para comparar cómo influye el recorrido del vehículo en su valor comercial.
* **Interactividad en tiempo real:** Gráficos dinámicos ajustables construidos con Plotly.
